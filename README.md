# The Complete Web Development Bootcamp

Course materials for a full-stack web development course, covering everything from HTML basics to blockchain deployment.

## What's Covered

- **Front End:** HTML5, CSS3, Flexbox, Grid, Bootstrap, Web Design, DOM
- **JavaScript:** ES6, React.js
- **Tools:** Unix Command Line, Git & GitHub
- **Back End:** Node.js, Express.js, EJS, APIs
- **Databases:** SQL, PostgreSQL, MongoDB
- **Deployment:** GitHub Pages, Heroku, MongoDB Atlas
- **Security:** Authentication, Hashing, OAuth 2.0
- **Web3:** Blockchain dev, crypto tokens, NFT marketplace

## Structure

Each module has its own folder with notes and exercises, in the order listed above.
